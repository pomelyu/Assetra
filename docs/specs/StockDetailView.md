# StockDetailView

## Purpose

呈現單一股票跨投資帳戶的持有狀態、損益與完整事件歷史。

## Information

- 顯示股票名稱、代號、市場、現價、總股數、總現值與未實現損益。
- 顯示 FIFO 剩餘批次推導的成本，以及累計賣出已實現損益與股息收益。
- 可依投資帳戶及事件類型（全部、買入、賣出、股息）篩選，並按日期分組。
- 每筆事件顯示日期、帳戶、類型、股數與單價或股息金額、費用及結算金額。

## Actions and Routing

- 點選事件進入 `StockTransactionView` 編輯同一來源事件。
- 新增交易進入 `StockTransactionView`，預填目前股票與帳戶篩選。
- 返回 `StockView` 時保留其篩選與捲動狀態。

## Data and Rules

- 賣出依各投資帳戶內最早買入批次依序沖銷，不得跨帳戶配對成本。
- 股息顯示於此股票歷史，同一事件亦投影為資金來源帳戶的收入。
- 股息與賣出改變投資帳戶已實現損益，但不增加投資帳戶現值。
- 已結清股票仍保留全部歷史與累計已實現損益。

## States

- 無事件時顯示空狀態與新增交易入口。
- 缺少即時行情時顯示最後成功價格及時間；不可把現值清零。
- 篩選無結果時允許一鍵恢復全部事件。

## Acceptance Criteria

- 顯示的持股數量等於買入減賣出，且 FIFO 成本可由事件歷史重現。
- 同一股息在股票與資金來源帳戶中可追溯為同一事件。
- 篩選只改變呈現範圍，不改變保存的損益或批次計算。
