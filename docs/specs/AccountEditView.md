# AccountEditView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

提供三類帳戶的共通編輯欄位與一般帳戶表單，並以初始數值納入既有資產。股票／投資帳戶的資金來源欄位由 `AccountEditView-invest` 呈現。

## Inputs

- 帳戶名稱、報表分類、帳戶幣別與備註。
- 建立帳戶時選擇類型：一般（GENERAL）、股票（STOCK）、投資（INVESTMENT）；選擇股票或投資時切換至 `AccountEditView-invest` 狀態。編輯既有帳戶時只顯示類型，不允許變更。
- 一般／投資帳戶可輸入初始成本與初始價值，不要求期初基準日；股票帳戶兩項固定為 0，不可編輯。

## Data and Rules

- 初始成本與初始價值只代表帳戶建立時的起始狀態；最終值由它們與後續交易推導。
- 使用者不得直接覆寫目前成本、現值或損益；校正須自行建立交易。
- 分類只決定資產與報表分組，不決定帳戶行為。
- 帳戶建立後一律不可變更帳戶類型；已有財務歷史時也不可變更幣別。任何變更都不可使既有資金來源關聯失效。
- 一般帳戶不設定資金來源；初始數值與交易後餘額可以為負。
- 更新時間不改變期初值的效力；期初值始終是交易歷史之前的基準。
- 帳戶不可刪除，只能封存；可在之後重新啟用。

## Actions and Routing

- 儲存後回到來源 view 並刷新帳戶摘要。
- 取消不保存變更。
- 建立時選擇股票／投資帳戶會進入 `AccountEditView-invest`，並保留已輸入的共通欄位；編輯時依既有類型直接進入對應狀態。
- 封存前顯示影響；封存後不得再成為新交易的可選帳戶。

## Validation and States

- 名稱、分類與幣別必填；數值格式必須符合選定幣別。
- 儲存中防止重複提交；失敗時保留使用者輸入。
- 編輯封存帳戶時提供重新啟用，而不是新增同名替代帳戶。

## Acceptance Criteria

- 新一般帳戶在沒有交易時顯示其初始成本與初始價值。
- 後續交易只在初始值上累積，不會覆寫起始資料。
- 編輯既有帳戶時無法提交不同的帳戶類型。
- prototype 的「帳戶成本／帳戶現值」文案不得出現在正式欄位名稱中。
