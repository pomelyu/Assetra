# AccountEditView

## Purpose

建立或編輯一般帳戶，並以初始數值納入使用者在本程式啟用前已存在的資產。

## Inputs

- 帳戶名稱、報表分類、帳戶幣別與備註。
- 投資帳戶開關；開啟後切換到 `AccountEditView-invest` 的欄位狀態。
- 初始成本與初始價值；不要求使用者輸入期初基準日。

## Data and Rules

- 初始成本與初始價值只代表帳戶建立時的起始狀態；最終值由它們與後續交易推導。
- 使用者不得直接覆寫目前成本、現值或損益；校正須自行建立交易。
- 分類只決定資產與報表分組，不決定帳戶行為。
- 幣別變更不得靜默重解釋既有數值；有歷史資料時須阻止或要求明確的遷移流程。
- 帳戶不可刪除，只能封存；可在之後重新啟用。

## Actions and Routing

- 儲存後回到來源 view 並刷新帳戶摘要。
- 取消不保存變更。
- 開啟投資帳戶時進入 `AccountEditView-invest`，保留已輸入的共通欄位。
- 封存前顯示影響；封存後不得再成為新交易的可選帳戶。

## Validation and States

- 名稱、分類與幣別必填；數值格式必須符合選定幣別。
- 儲存中防止重複提交；失敗時保留使用者輸入。
- 編輯封存帳戶時提供重新啟用，而不是新增同名替代帳戶。

## Acceptance Criteria

- 新帳戶在沒有交易時顯示其初始成本與初始價值。
- 後續交易只在初始值上累積，不會覆寫起始資料。
- prototype 的「帳戶成本／帳戶現值」文案不得出現在正式欄位名稱中。
