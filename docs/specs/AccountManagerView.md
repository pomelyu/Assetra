# AccountManagerView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

集中管理所有一般、股票與投資帳戶的建立、編輯、封存及重新啟用。

## Information

- 分別列出使用中與已封存帳戶。
- 每列顯示名稱、一般／股票／投資類型、分類、幣別，以及股票／投資帳戶的同幣別一般資金來源帳戶。
- 可依狀態、類型或分類篩選。

## Actions and Routing

- 新增帳戶 → `AccountEditView` 選擇類型；股票／投資帳戶使用 `AccountEditView-invest` 表單狀態。
- 編輯一般帳戶 → `AccountEditView`；編輯股票／投資帳戶 → `AccountEditView-invest`。
- 帳戶類型只在建立時選擇；管理與編輯流程均不提供類型變更。
- 封存前顯示影響並要求確認；已封存帳戶可重新啟用。
- 帳戶不提供永久刪除操作。

## Data and Rules

- 封存保留初始值、交易、部位、分類、快照及所有跨帳戶關聯。
- 封存帳戶不得用於新交易、資金來源或新帳戶預設值。
- 封存帳戶不可編輯；其 `UPDATED_AT` 作為封存時間，自該月份起在歷史總資產中計為 0。
- 若其他使用中的股票／投資帳戶仍把該帳戶設為資金來源，必須先改派或阻止封存。
- 重新啟用使用同一帳戶識別與快照，不建立副本；重新啟用後視為過去一直啟用，不保留或重建封存區間。

## States

- 無帳戶時顯示新增入口；只有封存帳戶時仍可切換查看。
- 封存或重新啟用失敗時維持原狀態並顯示原因。

## Acceptance Criteria

- UI 中任何帳戶都只能封存，不能永久刪除。
- 封存不刪除快照或事件關聯，但會使封存月份起的歷史總資產不再計入該帳戶；重新啟用會讓所有月份重新按快照計算。
- 重新啟用後帳戶可再次用於新交易，且歷史連續。
