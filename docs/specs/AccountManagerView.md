# AccountManagerView

## Purpose

集中管理所有一般與投資帳戶的建立、編輯、封存及重新啟用。

## Information

- 分別列出使用中與已封存帳戶。
- 每列顯示名稱、一般／投資屬性、分類、幣別，以及投資帳戶的資金來源帳戶。
- 可依狀態、類型或分類篩選。

## Actions and Routing

- 新增一般帳戶 → `AccountEditView`。
- 編輯一般帳戶 → `AccountEditView`；編輯投資帳戶 → `AccountEditView-invest`。
- 封存前顯示影響並要求確認；已封存帳戶可重新啟用。
- 帳戶不提供永久刪除操作。

## Data and Rules

- 封存保留初始值、交易、部位、分類、快照及所有跨帳戶關聯。
- 封存帳戶不得用於新交易、資金來源或新帳戶預設值。
- 若其他投資帳戶仍把該帳戶設為資金來源，必須先改派或阻止封存。
- 重新啟用使用同一帳戶識別與歷史，不建立副本。

## States

- 無帳戶時顯示新增入口；只有封存帳戶時仍可切換查看。
- 封存或重新啟用失敗時維持原狀態並顯示原因。

## Acceptance Criteria

- UI 中任何帳戶都只能封存，不能永久刪除。
- 封存不改變過去報表與事件關聯。
- 重新啟用後帳戶可再次用於新交易，且歷史連續。
