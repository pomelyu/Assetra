# AccountTransactionView

## Purpose

新增或編輯一般帳戶現金流，以及無法由股票行情自動估值的手動投資事件。

## Transaction Types

- 一般帳戶：轉帳、收入、支出。
- 投資帳戶：買入、賣出、利息、損益調整。
- 股票買入、賣出與股息可在帳戶明細投影，但須改由 `StockTransactionView` 編輯。

## Inputs

- 共通：類型、日期、目標帳戶、必要的對方帳戶、幣別、費用及備註。
- 轉帳：來源扣款金額與目標入款金額；跨幣別時允許兩端結算額不同。
- 收入／支出：帳戶實際增加／減少金額。
- 手動投資買入：投資成本、初始現值及資金來源扣款。
- 手動投資賣出：被沖銷成本、減少的現值與資金來源實際入款。
- 利息：資金來源實際入款。
- 損益調整：投資現值的增加或減少，不產生現金流。

## Data and Rules

- 轉帳是連結兩個帳戶的單一事件；兩端不可分開編輯。
- 一般帳戶的收入、支出與轉帳使成本及現值等額變動，不改變損益。
- 手動投資買入增加投資成本與現值，並扣減資金來源帳戶。
- 手動投資賣出同時減少成本與現值；實際入款與沖銷成本的差額計入已實現損益。
- 利息增加投資帳戶已實現損益並增加資金來源帳戶成本與現值，不增加投資現值。
- 損益調整只改變投資現值與未實現損益，不改變成本或任何帳戶現金流。

## Actions, Validation and States

- 儲存後刷新所有受影響帳戶與報表；取消不保存。
- 編輯或刪除事件時須原子性更新或回復所有關聯效果。
- 帳戶須未封存；金額、幣別及必要關聯須有效，扣款或沖銷不得超出可用值。
- 儲存中防止重複提交；失敗時保留表單與明確錯誤。

## Acceptance Criteria

- 每個事件類型的成本、現值、損益與現金流效果符合上述規則。
- 跨帳戶事件只建立一次，兩端顯示一致且可追溯。
- 手動投資賣出能由成本與實收款正確推導已實現損益。
