# CategoryManagerView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

管理用於 `AssetView` 與 `ReportView` 的資產分類名稱、順序與色彩。

## Information

- 列出所有分類、色彩、排序、引用該分類的帳戶數。
- 所有分類具有相同的可編輯能力及穩定識別；依目前 schema 不要求顯示分類是否源自預設值。

## Actions

- 新增分類；重新命名、變更色彩及調整排序。
- 刪除未被使用的分類。
- 刪除使用中分類前，必須選擇替代分類並一次重新指派所有相關帳戶。

## Data and Rules

- 重新命名不得改變分類識別或任何歷史關聯。
- 分類只影響分組、排序與視覺映射，不改變帳戶的一般／股票／投資類型或會計規則。
- 分類名稱須在目前語言脈絡下可辨識且不可為空；色彩重複可以接受，但須保持圖例可辨識。
- 系統必須始終保留至少一個可指派分類。

## States

- 無法載入時提供重試，不允許在不完整資料上重新指派。
- 保存或重新指派失敗時整體回復，不得留下部分帳戶使用已刪除分類。

## Acceptance Criteria

- 名稱、色彩與順序變更會同步反映於資產篩選及報表。
- 任何帳戶都不會引用已刪除分類。
- 分類修改不會改變資產金額或歷史快照內容。
