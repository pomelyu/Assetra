# StockTransactionView

## Purpose

新增或編輯股票的買入、賣出與股息事件，並同步其資金來源帳戶現金流。

## Inputs

- 股票、交易類型、交易日期、投資帳戶及其資金來源帳戶。
- 買入／賣出：股數、每股價格、交易幣別、手續費與稅。
- 股息：入款金額、幣別、費用或稅。
- 可選備註；顯示依輸入即時計算的結算總額。

## Actions and Routing

- 儲存成功後回到來源 view，並刷新所有受影響的摘要與歷史。
- 取消不保存變更。
- 編輯既有事件時可刪除；刪除前須確認並完整回復其所有投影效果。

## Data and Rules

- 買入：建立持股批次；含費用的支出計入投資成本；資金來源帳戶記為「買入（扣款）」。
- 賣出：依 FIFO 沖銷成本；實收金額扣除費用與稅，差額計入已實現損益；資金來源帳戶記為「賣出（入款）」。
- 股息：不改變股數、成本或投資帳戶現值；增加投資帳戶已實現損益，並在資金來源帳戶記為「收入（入款）」。
- 資金來源帳戶的成本與現值隨淨現金流等額變動，因此不產生該帳戶損益。
- 選擇投資帳戶時，資金來源帳戶會隨投資帳戶更改，但可以手動選擇其他的資金來源帳戶。
- 同一事件的股票紀錄與帳戶投影不可各自獨立編輯。

## Validation and States

- 必填欄位、正數金額與幣別必須有效；賣出股數不得超過該帳戶可用持股。
- 投資帳戶必須未封存且具資金來源帳戶；事件日期不得早於必要的前置批次。
- 儲存中防止重複提交；失敗時保留輸入並顯示可修正原因。

## Acceptance Criteria

- 每種事件只需儲存一次，即可在股票與資金來源帳戶看到一致結果。
- 編輯或刪除歷史買入後，所有後續 FIFO 結果會重新計算或因無效而被阻止。
- 畫面預覽的結算額與儲存後結果一致。
