# StockTransactionView

## Purpose

新增或編輯股票帳戶的買入、賣出與股息事件，同步一般資金來源帳戶的現金流。資料欄位及 API 依 [schema](../schema.md)。

## Inputs

- 共通：股票、交易類型、交易日期與時間（台北時間，24 小時制 HH:mm）、股票帳戶（STOCK）、一般資金來源帳戶（GENERAL）及可選備註。
- 買入／賣出：股數 QUANTITY、每股價格 UNIT_PRICE、合併手續費與稅的 FEE；無費用時填零。
- 股息：DIVIDEND_AMOUNT；沒有股數、單價或費用欄位。
- 幣別由標的及帳戶決定；標的、股票帳戶與一般資金帳戶必須同幣別。
- 可顯示推導的買入扣款／賣出入款及成本損益估算，不要求額外的預覽確認步驟；不額外輸入成交總額、交割總額或交易匯率。

## Actions and Routing

- 選擇股票帳戶時預填其資金來源；可改選其他未封存、同幣別的一般帳戶，事件保存實際使用的關聯。
- 儲存成功後返回來源 view，刷新受影響的帳戶、股票摘要及歷史。
- 取消不保存；刪除既有事件須確認，並完整回復兩端效果。

## Data and Rules

- 買入成本與一般帳戶扣款＝股數 × 單價 ＋ FEE。
- 賣出淨收入與一般帳戶入款＝股數 × 單價 − FEE；已實現損益＝淨收入 − FIFO 沖銷成本。
- FIFO 只在同一股票帳戶、同一股票內匹配買入批次；部分賣出按股數分攤買入費用，該批次最後沖銷時吸收尾差。
- 剩餘未實現損益＝剩餘股數 × 目前股價 − 剩餘 FIFO 成本。
- 股息等額增加股票帳戶已實現損益及一般帳戶成本、現值；不改變股數、持股成本或股票帳戶現值，且不收費。
- 一般資金帳戶顯示買入扣款、賣出入款或股息收入；其成本與現值等額變動，不產生一般帳戶損益。
- 所有投影共用同一事件；不另建一般收入／支出事件。交易編修重算後續部位與 FIFO，不覆寫已保存週快照。

## Validation and States

- 只接受 STOCK_BUY、STOCK_SELL、STOCK_DIVIDEND；股票帳戶與一般資金帳戶須未封存且類型、幣別相符。
- 股數及價格必須為正，適用費用非負；賣出不得超過事件當時的可用持股。
- 成交金額先四捨五入至幣別最小單位，再加減費用；FIFO 分攤成本同樣四捨五入，最後沖銷吸收剩餘尾差。
- 尚無報價仍可儲存交易、計算股數及成本；現值標示尚無報價，不用成交價替代。
- 一般資金帳戶允許負餘額，不因扣款超過餘額而阻擋買入。
- 儲存中防止重複提交；失敗保留輸入並顯示原因。

- 預填目前台北日期與分鐘；允許修改，但不得晚於現在。同分鐘依系統新增順序計算，編輯不改變該順序。
- 使用者填完表單按確定後才建立 input，直接呼叫 create/update；可選的預覽不是必要前置步驟。成功返回，失敗保留表單並顯示原因。
- 交易任一端（修改前後皆檢查）涉及封存帳戶時，禁止新增、修改及刪除，須先重新啟用。

## Acceptance Criteria

- 股票事件與一般帳戶投影只儲存一次，兩端金額一致。
- 股息表單不出現費用；買賣僅有一個合併費用欄位。
- 編修歷史事件後重算 FIFO；若會造成後續超賣則整筆操作失敗。
- 可選預覽與儲存共用計算規則，儲存時重新驗證當前歷史，費用不重複加減。
