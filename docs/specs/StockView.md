# StockView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

提供所有股票帳戶中股票部位的總覽、篩選與交易入口，不代表全資產總覽。

## Information

- 顯示持有中股票的總成本、總現值、未實現損益及報酬率，統一換算為基礎幣別。
- 每列顯示名稱、代號、市場、成本、現值、未實現損益與報酬率。
- 市場篩選包含全部、台股與美股；帳戶篩選只列未封存的股票帳戶。
- 已結清區塊顯示零持股股票的累計已實現損益，預設可收合。
- 顯示最後成功的行情與匯率更新時間；過期資料須有明確標示。

## Actions and Routing

- 切換市場或帳戶篩選，只影響清單與其摘要。
- 點選股票進入 `StockDetailView`，並保留目前篩選脈絡。
- 新增交易進入 `StockTransactionView`；若已有帳戶篩選，預填該帳戶。
- 手動更新行情與匯率；失敗時保留最後成功資料並顯示非阻斷式錯誤。

## Data and Rules

- 同一股票跨帳戶的列為合併摘要；帳戶層明細由 `StockDetailView` 呈現。
- 持有中與已結清由目前總股數是否大於零判定。
- 已實現損益與股息不加入持有部位現值；總覽收益指持有中部位的未實現損益。
- 缺少有效行情或匯率時不得以零替代，應沿用最後成功值或標示無法估值。

## States

- 無股票交易時顯示空狀態與新增交易入口。
- 篩選無結果時保留篩選器並提供清除篩選操作。
- 更新中不得清空既有清單或阻止離線瀏覽。

## Acceptance Criteria

- 篩選後的摘要與可見部位一致。
- 點選持有中或已結清股票皆能進入正確明細。
- 個別股票合計等於目前篩選範圍的摘要，且不重複計算帳戶彙總。
