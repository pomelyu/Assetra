# AccountDetailView

## Purpose

呈現單一帳戶的目前財務狀態與事件歷史，並提供交易及帳戶設定入口。

## Information

- 顯示帳戶名稱、一般／投資屬性、分類、幣別、成本、現值、已實現與未實現損益。
- 一般帳戶通常因成本與現值等額變動而不產生損益。
- 投資帳戶顯示持有部位彙總；股息、利息與賣出收益列入已實現損益但不加入現值。
- 歷史依日期分組，可按帳戶適用的事件類型及入款／扣款方向篩選。
- 多視圖投影事件須顯示其來源，例如股票名稱或對方帳戶。

## Actions and Routing

- 點選事件進入 `AccountTransactionView`；股票事件改由 `StockTransactionView` 維護。
- 新增手動事件進入 `AccountTransactionView`，預填目前帳戶。
- 編輯帳戶進入 `AccountEditView` 或其投資帳戶狀態。

## Data and Rules

- 一般帳戶適用轉帳、收入與支出。
- 投資帳戶另適用買入、賣出、利息及損益調整；股票事件也可唯讀投影於此。
- 同一轉帳在兩端顯示為同一事件的相反方向，不得重複計入。
- 封存不影響明細瀏覽、歷史計算或事件關聯。

## States

- 無交易時仍顯示初始成本、初始價值及新增交易入口。
- 篩選無結果時提供恢復全部事件操作。
- 關聯事件資料不完整時顯示錯誤狀態，不自行建立補償數值。

## Acceptance Criteria

- 摘要可由初始值、部位及事件歷史重現。
- 投影事件會導向唯一可編輯來源。
- 封存帳戶仍可完整瀏覽，但不允許新增交易。
