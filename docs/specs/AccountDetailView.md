# AccountDetailView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

呈現單一帳戶的目前財務狀態與事件歷史，並提供交易及帳戶設定入口。

## Information

- 顯示帳戶名稱、一般／股票／投資類型、分類、幣別、成本、現值、已實現與未實現損益。
- 一般帳戶通常因成本與現值等額變動而不產生損益。
- 股票帳戶顯示股票部位彙總與 FIFO 損益；投資帳戶顯示手動事件推導的成本、現值及比例平均成本損益。
- 股息歸屬股票帳戶、利息歸屬投資帳戶；股息、利息與賣出損益列入已實現損益，入款進入一般資金帳戶。
- 歷史依台北日期分組，顯示月日（不顯示時分）；按完整交易時間由近到遠排列，同分鐘依新增順序倒序排列。可按帳戶適用的事件類型及入款／扣款方向篩選。
- 多視圖投影事件須顯示其來源，例如股票名稱或對方帳戶。

## Actions and Routing

- 點選事件進入 `AccountTransactionView`；股票事件改由 `StockTransactionView` 維護。
- 新增事件按帳戶類型分流：一般／投資帳戶進入 `AccountTransactionView`，股票帳戶進入 `StockTransactionView`，預填目前帳戶。
- 編輯一般帳戶進入 `AccountEditView`；股票／投資帳戶使用 `AccountEditView-invest` 狀態。

## Data and Rules

- 一般帳戶適用轉帳、收入與支出。
- 股票帳戶只適用股票買入、賣出與股息；投資帳戶只適用手動買入、賣出、利息及損益調整。
- 一般資金帳戶也顯示股票／投資事件的現金流投影；事件仍由原始類型的編輯器維護。
- 同一轉帳在兩端顯示為同一事件的相反方向，不得重複計入。
- 封存不刪除明細、快照或事件關聯；封存日期起的歷史總資產以 0 計算。重新啟用後不保留封存區間，歷史日期重新按快照計算。

## States

- 無交易時，一般／投資帳戶顯示初始成本與初始價值，股票帳戶成本與現值皆顯示 0；交易清單顯示「尚未建立資料」，未封存帳戶提供適用的新增交易入口。
- 篩選無結果時提供恢復全部事件操作。
- 關聯事件資料不完整時顯示錯誤狀態，不自行建立補償數值。

## Acceptance Criteria

- 摘要可由初始值、部位及事件歷史重現。
- 投影事件會導向唯一可編輯來源。
- 封存帳戶仍可完整瀏覽，但任一端涉及封存帳戶的交易均不允許新增、修改或刪除。
- 有持股但未曾取得報價時，成本仍可計算，現值標示尚無報價，不以零或買入價替代。
