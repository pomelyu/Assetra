# DataManagerView

## Purpose

匯出完整本地資料備份，並從本程式產生的相容備份完整還原資料。

## Export

- 將資料庫各 table 匯出為獨立 CSV，並封裝成單一可分享的備份檔。
- 備份包含格式／schema 版本、建立時間、table 清單及完整性資訊。
- 匯出內容須足以重建帳戶、分類、交易、跨事件關聯、行情／匯率資料與月估值快照。
- 匯出成功後提供本地或系統分享儲存；取消分享不視為資料錯誤。

## Import

- 只接受本程式匯出的備份，不支援任意 CSV、Excel 或券商對帳單。
- 寫入前驗證封裝、版本、必要 table、欄位、資料型別、唯一性、引用關係及完整性資訊。
- 驗證成功後顯示來源日期、資料量及「將完整覆蓋目前資料」警告，再要求確認。
- 匯入必須原子性替換全部本地資料；任何失敗都保留匯入前狀態。

## Actions and States

- 匯入與匯出期間顯示進度並防止重複啟動。
- 格式過新、損毀或資料不一致時停止匯入，提供可理解的原因；不得嘗試部分匯入。
- 完成匯入後重新載入全應用狀態，並顯示成功摘要。
- 檔案選取取消、權限拒絕與儲存空間不足須分別處理。

## Security and Rules

- 備份不得包含生物辨識憑證、裝置金鑰或第三方秘密。
- 匯入不合併目前資料，也不依名稱猜測或去除重複項目。
- CSV 的 table 邊界是交換格式，不在本 spec 固定實際 schema。

## Acceptance Criteria

- 對同版本資料執行匯出後再匯入，可還原所有領域資料與關聯。
- 無效或中途失敗的匯入不會改變任何現有資料。
- 使用者在確認前能明確知道目前資料將被完整覆蓋。
