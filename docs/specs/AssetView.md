# AssetView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

以帳戶為單位呈現所有資產，提供全資產總覽、分類篩選及帳戶交易入口。

## Information

- 顯示全資產總成本、總現值、總收益與收益率，統一換算為固定基礎幣別 TWD。
- 依可用分類提供篩選；全部分類顯示所有未封存且應納入總覽的帳戶。
- 每列顯示帳戶名稱、分類、幣別、成本、現值、收益與收益率。
- 股票帳戶列顯示股票部位彙總；投資帳戶列顯示手動投資摘要，兩種類型各自計算。
- 顯示最後成功行情與匯率的更新時間及過期狀態。

## Actions and Routing

- 切換分類只影響清單及摘要。
- 點選帳戶進入 `AccountDetailView`。
- 新增交易進入 `AccountTransactionView`；若已有分類脈絡可作為預設選項。
- 手動更新行情與匯率；失敗不阻止離線瀏覽或記帳。

## Data and Rules

- 一般帳戶的成本與現值由初始值及後續交易推導。
- 股票帳戶彙總其股票部位成本及現值；投資帳戶由初始值、買賣、利息與損益調整推導摘要，不持有股票。
- 三種帳戶皆可指派報表分類；分類不決定帳戶類型或其交易行為。
- 封存帳戶不出現在目前清單；快照仍保留，但歷史報表依 schema 的封存日期與重新啟用規則決定是否計入。
- 無成本但有現值時，收益率顯示為不可計算，不得除以零。

- 有持股但未曾取得報價時，成本仍可計算，現值標示尚無報價；相關目前總覽標示估值未齊全，不以零或成交價代替。缺少換算匯率時同樣明確標示。

## States

- 無帳戶時顯示建立帳戶的引導。
- 篩選無結果時保留分類列並提供清除篩選操作。
- 任一資產無法換算時，標示該列並避免顯示不完整的誤導總額。

## Acceptance Criteria

- 可見帳戶的換算數值合計與目前摘要一致。
- 股票部位與帳戶彙總只計入一次，且分類變更會同步反映於總覽與報表。
- 過期或離線資料不會被顯示為零。
