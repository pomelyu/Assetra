# AssetView

## Purpose

以帳戶為單位呈現所有資產，提供全資產總覽、分類篩選及帳戶交易入口。

## Information

- 顯示全資產總成本、總現值、總收益與收益率，統一換算為基礎幣別。
- 依可用分類提供篩選；全部分類顯示所有未封存且應納入總覽的帳戶。
- 每列顯示帳戶名稱、分類、幣別、成本、現值、收益與收益率。
- 投資帳戶列顯示其持有部位彙總，不額外疊加一份帳戶資產。
- 顯示最後成功行情與匯率的更新時間及過期狀態。

## Actions and Routing

- 切換分類只影響清單及摘要。
- 點選帳戶進入 `AccountDetailView`。
- 新增交易進入 `AccountTransactionView`；若已有分類脈絡可作為預設選項。
- 手動更新行情與匯率；失敗不阻止離線瀏覽或記帳。

## Data and Rules

- 一般帳戶的成本與現值由初始值及後續交易推導。
- 投資帳戶的成本與現值為其股票部位與手動投資部位總和。
- 投資帳戶可分類為任意報表分類；分類不決定其交易行為。
- 封存帳戶不出現在預設清單，但其歷史仍保留於歷史報表。
- 無成本但有現值時，收益率顯示為不可計算，不得除以零。

## States

- 無帳戶時顯示建立帳戶的引導。
- 篩選無結果時保留分類列並提供清除篩選操作。
- 任一資產無法換算時，標示該列並避免顯示不完整的誤導總額。

## Acceptance Criteria

- 可見帳戶的換算數值合計與目前摘要一致。
- 投資帳戶部位只計入一次，且分類變更會同步反映於總覽與報表。
- 過期或離線資料不會被顯示為零。
