# SettingView

## Purpose

集中提供帳戶、分類、資料與應用偏好設定的入口，不在本頁直接編輯領域資料。

## Information and Routing

- 帳戶管理 → `AccountManagerView`。
- 報表分類設定 → `CategoryManagerView`。
- 資料匯入與匯出 → `DataManagerView`。
- 應用設定顯示目前外觀、語言、行情更新方式與安全狀態。
- 關於區顯示版本及回饋入口。

## Actions and Rules

- 外觀支援跟隨系統、淺色與深色。
- 語言至少支援繁體中文與 English；切換後不改變保存的領域資料。
- 數據更新可設定手動、每 15 分鐘或收盤後；離線時延後而非視為成功。
- 生物辨識鎖只有在裝置支援並完成驗證後才能啟用。
- 雲端備份若尚未正式支援，須明確標示不可用，不得假裝已完成備份。

## States

- 讀取設定失敗時顯示可重試狀態，不以預設值覆寫既有設定。
- 設定保存失敗時恢復原值並說明原因。
- 不支援的裝置功能須禁用並提供原因。

## Acceptance Criteria

- 每個管理項目導向 overview 指定的唯一 view。
- 所有立即生效的偏好在重啟後仍保留。
- 安全或備份狀態不得只由畫面切換推定，必須反映實際成功結果。
