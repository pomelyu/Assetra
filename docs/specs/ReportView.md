# ReportView

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

以一致的帳戶彙總資料呈現資產分佈、成本與現值比較，以及歷史收益趨勢。

## Views

- 資產分佈：甜甜圈圖按分類呈現目前現值、占比與排序，中心顯示總現值。
- 成本與現值：按分類或帳戶比較成本與目前現值，使用相同基礎幣別。
- 收益趨勢：以週快照繪製歷史總成本與總現值，並以目前帳戶總和呈現「現在」，並顯示所選期間的淨收益及報酬率。
- 趨勢期間包含 3M、6M、1Y、3Y 與全部；起訖日期及納入的快照須明確。

## Actions

- 切換分析 view 或期間時更新圖表、圖例與摘要。
- 點選圖表項目顯示精確分類、日期、原始數值與占比或差額。
- 圖表色彩使用分類設定，且不能只靠顏色傳達漲跌或類別。

## Data and Rules

- 報表以一般、股票、投資三類帳戶的摘要為計算單位；股票帳戶已包含其部位，不再疊加個股。
- 現況圖使用最後成功行情與匯率換算為 TWD；歷史圖使用每帳戶、每週最多一份且保存完整日期 YYYY-MM-DD 的快照，包含當時原幣及 TWD 成本、現值與累計已實現損益。
- 新行情、匯率或歷史交易編修不得回寫既有快照。
- 計算歷史日期 D 時，每個帳戶取 `SNAPSHOT_DATE <= D` 的最近快照；不存在則以 0 計算。既有快照可向後延用，不要求所有帳戶同週都有快照，也不標示歷史日期完整性。
- 一週以台北時間週一至週日為界。未封存帳戶在當週首次成功取得所需行情／匯率後獨立建立快照；資料不足或更新失敗的帳戶暫不建立，不阻擋其他帳戶，成功後再補建當週快照；同週不覆寫。
- 「現在」依目前帳戶成本、持股與最新成功行情／匯率計算，不使用最近快照替代。未曾取得必要行情／匯率時標示估值未齊全，不以零或買入價補足。
- 目前封存的帳戶自封存 `UPDATED_AT` 換算為台北日期的當天起以 0 計算，較早日期仍使用最近快照；重新啟用後視為歷來皆啟用，所有歷史日期恢復最近快照算法。
- 無成本時報酬率為不可計算，不得除以零。

## States

- 無資產時顯示空狀態，不繪製零值假圖。
- 所選期間內完全沒有可用歷史快照時顯示歷史空狀態，但不隱藏可計算的「現在」；個別帳戶在歷史日期前尚無快照時以 0 計算。
- 現況行情過期時顯示最後更新時間；更新失敗不得產生新週快照。

## Acceptance Criteria

- 估值資料齊全時，各分類現值合計等於總現值，百分比合計僅容許顯示四捨五入誤差；缺值時不得把部分合計呈現為完整總額。
- 相同歷史日期的總成本、總現值與摘要使用一致的各帳戶最近快照；「現在」使用當前計算結果。
- 單獨新增某帳戶的較早快照後，自該日期至下一份快照前只改變此帳戶的歷史貢獻；其他無快照帳戶仍為 0。
- 切換分類名稱或色彩後，資產與報表呈現保持一致。
