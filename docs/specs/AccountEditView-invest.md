# AccountEditView-invest

資料欄位、計算規則與 Data API 依 [schema](../schema.md)。

## Purpose

AccountEditView 選擇股票（STOCK）或投資（INVESTMENT）類型後的表單狀態，負責同幣別一般資金帳戶設定。沿用既有 view 名稱，涵蓋兩種類型。

## Inputs

- AccountEditView 的共通欄位：名稱、類型、分類、幣別、初始數值與備註。
- 必須指定同幣別、未封存的一般帳戶（GENERAL）作為資金來源。
- 投資帳戶的初始成本與初始價值用於既有手動投資，不要求基準日。

## Data and Rules

- 帳戶類型與報表分類獨立；例如黃金 ETF 歸股票帳戶，但報表分類可為黃金。
- 股票帳戶只允許股票買入、賣出、股息，部位使用 FIFO；投資帳戶只允許手動買入、賣出、利息及損益調整，賣出使用比例平均成本。
- 股票／投資帳戶的扣款與入款皆投影至同幣別一般帳戶；不混用兩種帳戶的事件。
- 更換預設資金來源只影響新事件，舊交易保留實際使用的帳戶。
- 帳戶建立後不可變更帳戶類型，即使尚無財務歷史；已有財務歷史時也不可變更幣別。
- 投資帳戶初始值是交易歷史之前的基準；股票帳戶初始成本與初始價值固定為 0，不提供編輯，持股與成本由股票交易建立。
- 帳戶不可永久刪除，只能封存與重新啟用。

- 未封存的一般／投資帳戶可修改初始值，須在同一原子操作中重算並驗證全部受影響交易；造成後續無效賣出等情形時拒絕修改，既有週快照不變。股票帳戶初始值仍固定為 0。

## Actions and Routing

- 建立帳戶時以三類帳戶選擇器取代二元開關；建立流程可在儲存前切回一般帳戶。編輯既有帳戶時類型為唯讀。
- 儲存、取消、封存及重新啟用沿用 AccountEditView；股票與投資帳戶均須先完成資金來源設定。

## Validation and States

- 資金來源不得是自己、股票帳戶、投資帳戶、已封存帳戶或不同幣別帳戶。
- 初始數值遵循 schema 的幣別精度；股票帳戶必須兩項皆為 0，包含建立及備份匯入。不輸入交易匯率。
- 無合適資金來源時，引導建立同幣別一般帳戶。

## Acceptance Criteria

- 同一報表分類可包含三種帳戶，各自只提供允許的交易。
- 股票與投資帳戶皆無法在缺少有效資金來源時儲存。
- 新股票帳戶在沒有交易時成本與現值皆為 0；非零初始值不得儲存。
- 更換預設來源不改寫歷史；既有帳戶沒有類型切換操作。
